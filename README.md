# TaskFlow

Projeto base para a atividade prática de branches no Git/GitHub.

## Sobre

Uma lista de tarefas simples em HTML, CSS e JavaScript puro, usada como
base para praticar:

- Criação de branches por funcionalidade (`feature/...`)
- Correção de bugs em branches separadas (`bugfix/...`)
- Merges diretos e Pull Requests
- Colaboração com revisão de código

## Como rodar

Basta abrir o arquivo `index.html` no navegador.

## Estrutura

```
atividade-branchs/
├── index.html
├── style.css
├── script.js
└── README.md
```
